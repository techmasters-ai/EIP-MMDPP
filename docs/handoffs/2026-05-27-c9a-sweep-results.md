# C.9a — Offline calibration sweep

GT_TOP_K (critical-evidence definition) = top 30 by reranker score at max-permissive (no threshold, top_k=∞).

Columns:
- `cand` = candidates surviving min_sim + top_n cap (input to selection)
- `selected` = chunks the LLM would see (= min(top_k, cand))
- `sel_tok` = bge-m3 token count of selected chunks
- `cov(top30)` = % of GT top-30 refs that survive the config
- `gap` = min(reranker score in selected) − max(reranker score in excluded-but-in-cand)
- `rerank_ms` = est. (proportional to candidate count)
